# 悟典 — 论语数据说明

> 《论语》结构化数据基础，供「悟典」四书五经互动学习平台使用。

## 目录结构

```
data/
├── raw/              # 原始数据（预留，存放未经处理的原始文本）
├── processed/        # 清洗后的结构化数据（供前端/后端直接使用）
│   ├── lunyu.json           # 论语完整结构化数据
│   └── lunyu_quotes.json    # 论语名句精选合集
├── scripts/          # 数据处理脚本
│   └── build_lunyu.py       # 论语数据生成脚本
└── README.md         # 本说明文件
```

## 数据文件

### 1. `processed/lunyu.json` — 论语核心数据

《论语》20 篇的结构化数据，前三篇（学而、为政、八佾）为**完整章节**，含原文、白话翻译、生僻字注音释义、关键词；第 4–20 篇为**篇目概览 + 代表性章节**。

#### 结构说明

```jsonc
{
  "book": "论语",
  "author": "孔子弟子及再传弟子",
  "dynasty": "春秋",
  "description": "……",
  "total_chapters": 20,
  "chapters": [
    {
      "chapter_id": 1,              // 篇序号
      "chapter_title": "学而",       // 篇名
      "summary": "本篇以「学」为核心……",  // 篇章概要
      "verses": [
        {
          "verse_id": "1.1",        // 章节编号（篇号.章号）
          "title": "学习与修身",     // 章节小标题（可选）
          "original": "子曰：……",   // 原文
          "translation": "孔子说：……", // 白话翻译
          "annotations": [           // 生僻字注释
            {
              "char": "说",
              "pinyin": "yuè",
              "meaning": "同「悦」，愉快"
            }
          ],
          "keywords": ["学习", "温习"]  // 关键词标签
        }
      ]
    }
  ]
}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `verse_id` | string | 章节 ID，格式为「篇号.章号」 |
| `title` | string? | 章节小标题，部分章节可缺省 |
| `original` | string | 论语原文 |
| `translation` | string | 口语化白话翻译 |
| `annotations` | array | 生僻字/通假字/古今异义注释 |
| `annotations[].char` | string | 需注释的字 |
| `annotations[].pinyin` | string | 拼音（含声调标记） |
| `annotations[].meaning` | string | 释义 |
| `keywords` | array | 主题关键词，用于检索与分类 |

#### 统计数据

- 篇章数：**20**
- 章节数：**107**
- 注释数：**168**
- 前三篇完整章节数：学而 16 章 + 为政 24 章 + 八佾 26 章 = **66 章**

### 2. `processed/lunyu_quotes.json` — 名句精选

收录 **36 条**论语名句，每条包含原文、出处、现代翻译、现代应用场景及难度等级。

#### 结构说明

```jsonc
{
  "book": "论语",
  "description": "……",
  "total": 36,
  "quotes": [
    {
      "id": "q01",
      "original": "学而时习之，不亦说乎？",
      "source": "学而第一·1",       // 出处（篇名 + 章号）
      "translation": "学了知识并按时温习实践，不也很愉快吗？",
      "scene": "学习新技能后反复练习……",  // 现代应用场景
      "level": "初级"               // 难度等级：初级/中级/高级
    }
  ]
}
```

#### 难度等级说明

| 等级 | 说明 | 适用场景 |
|------|------|----------|
| 初级 | 字句浅显，寓意明确 | 日常引用、入门学习 |
| 中级 | 含生僻字或需背景理解 | 深入学习、写作引用 |
| 高级 | 涉及深层哲学或礼制 | 学术研究、专题讨论 |

## 脚本说明

### `scripts/build_lunyu.py`

**用途**：基于内置数据生成 `lunyu.json` 与 `lunyu_quotes.json`，无需联网。

**运行方式**：

```bash
python data/scripts/build_lunyu.py
```

**输出**：在 `data/processed/` 目录下生成两个 JSON 文件。

**数据来源**：所有原文与翻译基于公开经典文本内置编写，前三篇（学而、为政、八佾）为逐章完整校对。

## 扩展方式

### 1. 补充完整章节

第 4–20 篇目前收录代表性章节。如需补全，在 `build_lunyu.py` 对应篇章的 `verses` 列表中添加新的 `V(...)` 调用即可：

```python
V("4.5", "子曰：「……」", "孔子说：……",
  [A("某字", "mǒu", "释义")],
  ["关键词1", "关键词2"], "章节标题"),
```

### 2. 新增典籍

以论语为模板，创建新的生成脚本（如 `build_mengzi.py`），输出对应的 JSON 文件至 `processed/` 目录。保持结构一致以便平台统一调用。

### 3. 增强注释

在 `annotations` 数组中追加更多字词的注音释义，尤其关注通假字和古今异义词。

### 4. 扩展名句

在 `QUOTES` 列表中添加新的名句条目，遵循现有字段格式即可。

## 质量说明

- **原文准确性**：前三篇逐章录入，确保原文准确；第 4–20 篇选取的代表性章节同样严格校对。
- **翻译风格**：白话翻译追求通俗易懂、口语化，避免文言腔调。
- **注释规范**：涵盖生僻字注音、通假字标注、古今异义说明。
- **现代应用**：名句的现代应用场景贴近职场、家庭、社交等当代生活。
