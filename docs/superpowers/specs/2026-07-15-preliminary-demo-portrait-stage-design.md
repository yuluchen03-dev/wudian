# 悟典初赛 Demo 先贤肖像舞台替代规格

本规格取代 `2026-07-15-preliminary-demo-3d-redesign.md` 中关于程序化数字人、人物动作和对应验收标准的内容；其余产品、流程、商业与离线要求继续有效。

## 1. 变更原因

当前 Three.js 场景用基础几何体拼成孔子、孟子、老子半身像。它们缺少可信的人体比例、五官和服饰细节，视觉上更接近玩具人偶，反而削弱初赛作品的完成度。

本次调整不再追求低质量的“3D 数字人”。页面保留真实 3D 空间、镜头、灯光、案卷、典籍和观点关系线，将人物改成由现有高清肖像构成的立体先贤席位。页面统一使用“先贤肖像”“肖像席位”或“三贤席位”，不再宣称数字人。

## 2. 目标与边界

目标是让评委第一眼明确看到孔子、孟子、老子是人物，而不是几何人偶，同时保留数字思想剧场的空间感和交互反馈。

本次只修改人物呈现和与人物直接相关的提示文案，不修改：

- 三个精选职场案件。
- 七阶段会审状态机。
- 经典证据、关系类型与思想判牒。
- 价值调权逻辑。
- 企业试点和隐私边界。
- 离线 ZIP、无网络依赖与 20 MB 上限。

## 3. 方案选择

### 3.1 采用方案：3D 立体肖像席位

Three.js 本地加载 `confucius.png`、`mencius.png`、`laozi.png`，将每张肖像放入具有厚度的深色石质或金属屏风中。屏风包含肖像画面、窄边框、底座、背光和人物专属强调色，整体仍处于真实 3D 舞台并参与镜头透视。

肖像本身保持真实质感，不进行假 3D 拉伸，不附加几何头部、圆柱身体、假手臂或不自然的抬手动作。

### 3.2 不采用：继续优化程序化人偶

仅靠基础几何体增加眼睛、鼻子和胡须，仍然很难达到可信人物水平，还会继续放大“廉价 3D”问题。

### 3.3 不采用：引入外部写实 GLB 人物

外部模型存在肖像准确性、版权、贴图体积、加载稳定性和移动端性能风险，不适合当前离线初赛包。

## 4. 舞台与交互

三块肖像屏风继续使用三角席位布局，中央保留案卷和典籍。

- 选案：三贤肖像处于较暗的候场状态，人物仍可辨认。
- 举证：三块屏风与对应典籍建立颜色关联。
- 交锋：当前肖像席位前移、轻微转向中央并增强边缘光；其他席位后退并降低亮度。
- 调权：权重只改变席位高度、边框光和舞台灯光，不扭曲人物肖像。
- 落判：人物席位退入暗部，视觉焦点转向判牒。

人物动作只使用屏风整体的位移、转向、亮度和轻微视差。减少动态模式下直接切换最终状态，不执行镜头旅行或视差动画。

## 5. 文案调整

删除或替换以下表达：

- “3D 数字人”改为“3D 先贤肖像舞台”。
- “点击人物聚焦席位”改为“点击肖像切换立场”。
- “当前数字人前移”改为“当前肖像席位前移”。

产品核心定位不变：这是一场由经典证据驱动、由用户调权的中国思想会审。

## 6. 技术设计

`court-scene.js` 删除 `createSage` 及其几何身体和手臂动画，新增单一职责的 `createPortraitSeat`：

- 使用本地 `THREE.TextureLoader` 加载肖像。
- 将纹理标记为 sRGB，避免肤色偏灰。
- 用固定比例平面显示肖像，外层使用有厚度的屏风与底座。
- 暴露可动画的根节点、肖像材质、边框材质和权重值。
- 单张纹理加载失败时保留空屏风和人物对应色，不阻塞 DOM 流程。

`setActiveSage` 接口保持不变，避免影响 `app.js` 状态机。`setWeights` 改为控制屏风高度和光效，不再控制几何身体。

## 7. 移动端与降级

390px 移动端的 3D 场景一次突出一块肖像屏风，避免三张肖像互相遮挡。用户通过现有孔子、孟子、老子标签切换当前立场。

强制 2D 或 WebGL 失败时继续使用现有 DOM 肖像舞台。3D 与 2D 两种模式使用同一组本地图片，不增加网络请求。

## 8. 验证合同

自动验证需要确认：

- `court-scene.js` 使用 `THREE.TextureLoader` 和三张本地肖像路径。
- 不再存在 `createSage`、几何头部、几何身体或手臂动画。
- 页面不再出现“3D 数字人”表述。
- 2D 降级、减少动态和离线依赖合同继续通过。

浏览器验收需要确认：

- 1440px 首屏能直接辨认三块人物肖像，而不是人偶。
- 交锋时切换孔子、孟子、老子，当前肖像席位与 DOM 选中状态一致。
- 390×844 无水平溢出，当前肖像不遮挡标题、证据和操作按钮。
- Canvas 不是空白，案卷、典籍和观点关系线仍然存在。
- 强制 2D 和减少动态路径仍能完成七阶段流程。
- ZIP 小于 20 MB，解压后验证通过且无外部请求。

## 9. 成功标准

评委看到人物时不需要依赖名牌猜测“这是不是人”。画面应被理解为有意设计的先贤肖像剧场，而不是没有完成的 3D 人物模型。
