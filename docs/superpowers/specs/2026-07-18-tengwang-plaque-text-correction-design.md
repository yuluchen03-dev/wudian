# 滕王阁牌匾文字修正规格

## 目标

修正滕王阁主视觉中的生成式乱码，保证主匾准确显示“滕王阁”，下方小匾准确显示“瑰伟绝特”。

## 方案

- 以现有 `pavilion.png` 为编辑目标，保持楼阁结构、材质、光影、背景、比例和透明边缘不变。
- 清理两块牌匾上的错误字形，只修改牌匾文字区域。
- 使用支持完整中文字形的书法风格字体确定性渲染文字，并按原牌匾透视、字距、金色质感和明暗关系合成。
- 主匾按画面视觉顺序显示“滕王阁”；下匾显示“瑰伟绝特”。
- 输出新的版本化 PNG，不覆盖原始资产；项目引用切换到新文件。

## 验收标准

- 两处文字逐字正确、清晰可辨，没有伪汉字或多余笔画。
- 修正区域与牌匾透视、纹理、颜色和光照自然融合。
- 楼阁主体和页面布局没有可见变化。
- 新资产通过现有 PNG 资产校验，生产构建及滕王阁相关测试通过。
- 在桌面浏览器中实际加载页面，确认新图片生效且下方文字幕布仍正常显示。

## 回退与风险

- 保留原始 `pavilion.png`，需要时可仅切回资源引用。
- 图像模型不负责最终汉字字形，避免再次生成乱码；模型只用于必要的局部牌匾清理，最终文字由确定性合成完成。
