# 《滕王阁序》互动文境融合设计

## 状态

已确认。该设计把用户提供的 HTML 珠帘物理效果改造为悟典原生 React 页面，而不是嵌入 iframe 或直接执行原始全局脚本。

## 目标

- 在“趣味经典”下新增可直接访问的沉浸式《滕王阁序》互动文境。
- 保留参考效果最有辨识度的中央滕王阁、竖排文字珠帘和指针扰动物理反馈。
- 保留并本地化图片、文字和物理参数配置，新增默认关闭的音效开关。
- 复用悟典现有导航、纸墨色彩、字体和静态导出能力。
- 在路由切换、开发模式重复挂载和移动端触控下正确管理动画、监听器与音频资源。

## 非目标

- 不替换首页首屏，也不改造现有“探索”页。
- 不保留示例中的第三方品牌、导航文案或外链。
- 不把上传内容持久化到服务器或浏览器存储。
- 不引入 iframe、Web Component、第三方物理引擎或新的后端接口。
- 不重构与本功能无关的全局导航、首页或内容数据加载逻辑。

## 产品入口与路由

- 新页面路由为 `/content/tengwang-ge-xu`。
- `frontend/app/content/page.tsx` 的现有标签栏增加一个带地标图标的“文境”链接。它是独立路由入口，不加入现有 `Tab` 状态，也不改变金句、剧场和漫画的数据加载行为。
- 根导航保持不变。因为路径位于 `/content` 下，“更多 > 内容”会继续获得正确的激活状态。
- 页面保留全局 68px 导航和页脚。主体突破根布局的横向内边距，但仍遵守项目的 1440px 最大内容宽度。

## 页面架构

实现分为四个清晰边界：

1. `frontend/app/content/tengwang-ge-xu/page.tsx`
   - 服务端页面外壳。
   - 提供页面元数据并渲染客户端体验组件。
2. `frontend/components/content/tengwang/TengwangExperience.tsx`
   - 管理设置面板、上传图片、文字、物理参数、静音和重置状态。
   - 负责页面语义结构、默认内容和静态降级界面。
3. `frontend/components/content/tengwang/CurtainCanvas.tsx`
   - 拥有 Canvas、ResizeObserver、指针事件、动画帧和音频生命周期。
   - 仅通过明确 props 接收图片布局结果、文字、物理参数、声音状态和重置版本号。
4. `frontend/lib/curtainPhysics.ts`
   - 提供不依赖 React 或 DOM 的珠帘构建、Verlet 积分、约束和扰动计算。
   - 便于用确定性输入验证几何与边界条件。

页面样式放在同目录 CSS Module 中，避免原始 HTML 的 `:root`、`body`、`h1`、`.settings`、`.cursor` 等全局选择器污染应用。

## 静态资源

- 用户提供的透明滕王阁 PNG 复制到 `frontend/public/agens/content/tengwang-ge-xu/pavilion.png`。
- 使用图片真实尺寸 `1280 x 823`，避免原示例错误的宽高声明造成首帧跳动。
- 资源路径注册到 `frontend/lib/visualAssets.ts`，页面组件不散落硬编码路径。
- 默认图像提供准确替代文本；Canvas 只承载装饰性物理绘制并设为对辅助技术隐藏，经典标题和出处保留为真实 DOM 文本。

## 视觉构图

- 背景使用悟典的宣纸白、墨黑、黛青与朱砂变量，并增加低对比纸纤维纹理；不新增与现有系统冲突的品牌色。
- 透明滕王阁置于上方中央，珠帘从建筑底缘自然垂下。左下为“滕王阁序”大标题和“王勃”眉题，右下为简短作品出处。
- 参考图的编辑式不对称留白被保留，但删除“AI超级个人”、示例导航和无关进度装饰。
- 配置入口位于场景右上角，使用 `SlidersHorizontal` 图标和可访问名称。桌面展开右侧面板，移动端打开底部抽屉。
- 卡片圆角不超过 8px，设置面板不嵌套卡片；标题使用项目宋体，控制项使用项目无衬线字体。

## 珠帘物理

- 每列由一个固定锚点和若干质点组成，列内字符从上到下排列，整帘按古籍习惯从右向左阅读。
- 每帧执行 Verlet 积分、重力、摩擦和六轮距离约束。指针移动向作用半径内质点注入按距离衰减的位移。
- 桌面最多 26 列，窄屏最多 16 列；实际行列数按建筑宽度、可用高度和文字容量计算，始终保证至少 2 列和 2 行，不产生负数或空链。
- 默认参数与界面值一致：力度 72、范围 34、惯性 97；重力保持内部常量。力度映射为显示值除以 100，惯性映射为显示值除以 100。
- 动画仅在初始化、交互或珠帘尚未归稳时运行；达到稳定阈值后停止请求新帧。页面隐藏或画布离开视口时暂停，恢复可见后按需重绘。
- `prefers-reduced-motion` 下不执行装饰性入场动画，并使用更强阻尼让珠帘更快归稳；用户主动拖动仍然有效。

## 设置与状态流

设置面板包含：

- 图片：接受 PNG、JPEG、WebP，最大 8 MiB，解码后宽高均不得超过 8192px。
- 珠帘文字：最多 3000 个字符；物理画布按当前容量显示，输入框保留完整合法输入。
- 力度：20-110，默认 72。
- 范围：18-56，默认 34。
- 惯性：86-99，默认 97。
- 声音：默认关闭；开启后仅在用户手势发生时创建或恢复 AudioContext。
- “重置珠帘”：保留当前图片、文字与参数，只重建静止珠帘。
- “恢复默认”：恢复默认图片、文字、参数和静音状态，并撤销自定义对象 URL。

图片上传使用 `URL.createObjectURL`，新图片替换、恢复默认和组件卸载时都调用 `URL.revokeObjectURL`。所有自定义状态只存在当前页面会话中，刷新后恢复默认。

## 音频

- 保留原示例的轻量 Web Audio 合成碰撞声和左右声像，不加载音频文件。
- 默认静音，只有用户主动打开声音并在页面内发生指针手势后才创建 AudioContext。
- 限制并发声部和触发频率，防止快速移动造成削波或性能抖动。
- 静音时暂停音频上下文，组件卸载时关闭上下文并清空定时状态。
- 浏览器不支持 Web Audio 时，页面保持完整视觉交互，声音控制显示为不可用状态。

## 响应式与输入方式

- 1024px 及以上场景高度使用 `clamp(620px, calc(100svh - 68px), 860px)`，确保阁楼、珠帘、标题和设置按钮不互相遮挡。
- 721-1023px 场景高度使用 `clamp(700px, calc(100svh - 68px), 900px)`，收紧标题与说明区域并保持阁楼居中。
- 720px 及以下场景高度使用 `max(720px, calc(100svh - 68px))`，减少帘列、缩小标题并隐藏非必要的长说明；设置改为最大高度 `min(78dvh, 620px)` 的底部抽屉。
- 移动端交互区使用允许纵向滚动的触控策略；浏览器接管纵向滚动时停止当前珠帘拖动，避免整页被 Canvas 锁死。
- 精细指针设备保留正常系统指针，不隐藏光标。触控目标不小于 44px。

## 可访问性

- 设置按钮、静音按钮、重置按钮和上传控件都有明确中文名称、键盘焦点和不小于 44px 的点击区域。
- 设置面板使用对话框语义；打开时聚焦首个控件，支持 Escape 关闭、Tab 焦点循环，关闭后把焦点还给触发按钮。
- Canvas 被视为装饰性增强，不承载唯一信息。页面提供真实 DOM 标题、作者、出处和屏幕阅读器可访问的默认文本摘要。
- 错误提示使用 `role="status"` 或 `role="alert"`，不只依靠颜色表达。
- 文字与背景对比度遵守现有 UI 规范，正文至少 4.5:1，次级信息至少 3:1。

## 生命周期与性能

- 使用 ResizeObserver 监听场景容器，而不是只监听 `window.resize`；尺寸变化时按设备像素比重设 Canvas，并限制 DPR 上限为 2。
- 图片完成解码后再计算建筑底缘和珠帘锚点，避免加载前后的宽高比变化。
- 组件卸载时取消动画帧、断开 ResizeObserver 与 IntersectionObserver、移除页面可见性和指针监听、释放对象 URL，并关闭 AudioContext。
- React Strict Mode 重复挂载不得产生第二条动画循环或重复监听。
- 画布不可见、标签页隐藏或珠帘稳定时不持续占用动画帧。

## 降级与错误处理

- Canvas 2D 上下文不可用时，显示静态阁楼、标题、作者与正文摘要，并隐藏无效的物理参数控制；页面不得空白。
- 默认图片加载失败时显示文本构图和明确的资源错误状态；自定义图片解码失败时保留上一张有效图片并提示用户。
- 文件类型、体积或尺寸校验失败时不修改当前图片。
- Web Audio 不可用或启动失败时自动保持静音，不影响 Canvas。
- 任意不足高度或极端宽高比都通过最小行列数和边界夹取处理，不允许计算得到负行数、NaN 或空数组访问。

## 测试策略

1. 为 `curtainPhysics.ts` 添加确定性测试，覆盖珠帘最小尺寸、从右向左文字索引、扰动半径、约束后长度和极端视口边界。
2. 添加源码接线测试，锁定独立路由、内容页入口、CSS Module、默认参数、资源路径、清理调用、静音默认值和无障碍语义。
3. 运行现有完整前端测试，确认首页、内容、剧场、漫画、导航和静态资源接线不回归。
4. 运行生产构建与静态导出兼容检查，不依赖服务端运行时 API。
5. 启动本地开发服务器，在 1440x900、768x1024、390x844 三个视口执行浏览器验收：
   - 页面与 Canvas 非空，默认图片正确渲染。
   - 指针扰动后珠帘移动并最终归稳。
   - 设置面板/底部抽屉无溢出或遮挡。
   - 文字替换、三组滑杆、静音、重置珠帘和恢复默认生效。
   - 合法图片可替换，非法图片保留原状态并显示错误。
   - 移动端可以纵向滚动，无横向溢出。
   - 开启减少动态效果后仍可主动交互，且无多余装饰动画。

## 验收标准

- 页面视觉明显属于悟典，同时保留参考图可识别的阁楼与文字珠帘构图。
- 所有配置功能、默认静音、两种重置和移动端底部抽屉可用。
- 离开页面后没有继续运行的动画、监听器、对象 URL 或音频上下文。
- 390px、768px、1440px 视口无横向滚动、文字遮挡或控件越界。
