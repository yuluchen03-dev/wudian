# 悟典 UI 系统改版设计

## 目标

将悟典从卡片堆叠式“古风学习平台”改造成现代、克制、东方、可信的经典思想交互产品。首轮覆盖全局壳层、首页和圣贤问答主流程，不修改正在开发中的阅读器文件。

## 设计方向

采用“数字人文工作台”方向：以 NotebookLM 的信息组织为骨架，以 Perplexity 的引用关系为交互重点，以数字敦煌的留白与低饱和文化气质作为视觉语言。首页负责建立品牌与产品价值；问答页负责高效对话和可溯源依据；导航负责降低全站信息噪声。

未采用仿古卷轴方案，因为它会牺牲现代工具效率；未采用大图营销站方案，因为悟典的核心是可操作的问答和阅读，而非品牌宣传。

## 全局视觉系统

- 宣纸白 `#F5F1E8` 为页面底色，墨黑 `#242421` 为主文字。
- 黛青 `#334854` 作为主要命令色，朱砂 `#9E443A` 只用于引用、校验和品牌印记。
- 标题与经典原文使用宋体，现代说明、按钮与导航使用无衬线字体。
- 卡片圆角控制在 4-8px，减少大圆角、重阴影与装饰性胶囊标签。
- 文化图像使用现有圣贤肖像、场景图和典籍封面，配合低对比遮罩，不生成风格不一致的新头像。
- 动效只用于页面进入、引用展开和检索状态，并支持 `prefers-reduced-motion`。

## 首页

首屏采用不对称双栏：左侧是品牌名“悟典”、价值主张、主次入口与可信证据；右侧使用孔子场景图构成沉浸式文化画面，人物与典籍内容在首屏即被看见。首屏高度留出下一段内容提示。

首屏下方将原有每日一句、答题挑战、典籍书库重新组织为连续内容带：每日一句为主要文化内容，典籍封面形成横向编辑陈列，答题与学习进度为次级工具，不再把每个模块都做成同等强调的浮动卡片。

## 圣贤问答

桌面端在选定圣贤后采用三栏工作台：左栏放圣贤切换与历史入口，中栏放对话和输入，右栏放当前回答依据。移动端改为顶部圣贤切换、中部对话、底部固定输入和可展开依据。

初始状态不再使用三张同质大卡片，而使用一个主圣贤场景和紧凑圣贤列表。检索状态显示“理解问题、检索典籍、校验出处、组织回答”等可验证过程，不展示模型思维链。

## 导航

桌面主导航只保留首页、问道、阅读、论道、探索五个高频入口；复习、闯关、内容、社区等归入“更多”。品牌区使用方形朱砂印记加文字标识。移动端使用清晰抽屉，保证 44px 触控目标。

## 可访问性与响应式

- 正文对比度至少 4.5:1，次级文字至少 3:1。
- 所有图标按钮提供 `aria-label`，键盘焦点清晰可见。
- 主要交互尺寸不小于 44px。
- 重点检查 390px、768px、1440px 三档视口，无横向滚动和内容遮挡。

## 验证

- 增加源码接线测试，锁定新的首页层级、问答工作台和导航信息架构。
- 运行前端测试与生产构建。
- 启动开发服务器，在桌面和移动视口检查首屏、导航和问答页。
