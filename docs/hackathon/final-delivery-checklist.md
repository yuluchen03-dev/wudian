# 悟典 Trae 黑客松最终交付检查表

## 统一演示口径

- 主定位：可追溯的中国思想问答入口。
- 演示路线只讲：`/demo -> 问题落案 -> 经典举证 -> 百家交锋 -> 思想判牒 -> /about`。
- 默认 API：`http://localhost:8000/api`。
- 默认 mock：`NEXT_PUBLIC_USE_MOCK=false`。
- 可信回答统一表述：先检索、再生成、可追溯、检索不到不硬编。
- 安全边界：思想启发，不替代心理、医疗、法律或职业决策。

## 思想审判场运行检查

- [ ] `/demo` 首屏直接进入思想审判场，不再展示主持人指挥台或营销说明页。
- [ ] 无需登录即可在 90 秒内走完首个精选案件的四幕流程。
- [ ] 三个精选案件（职场认可、职业去留、功劳归属）均有可核验原文、出处、解释、适用边界、三家立场和行动建议。
- [ ] 自由提问使用真实后端；失败时原地保留内容并提供重试或稳定演示替代。
- [ ] 证据选择、追问、互问、站队和价值权重至少实际改变一次后续呈现或判牒排序。
- [ ] 界面明确显示 `curated`、`live` 或 `stable-demo` 模式标记。
- [ ] 稳定演示数据标注为 `演示稳定层：已加载经校验案件`，不冒充实时输出。

## 响应式与无障碍检查

- [ ] 桌面 1440px：无空白主场景、横向溢出、文字遮挡、按钮遮挡或布局跳动。
- [ ] 移动 390px：无横向滚动，底部操作位于安全区上方，证据抽屉不超过 70dvh，长中文可换行，落印不遮挡按钮。
- [ ] 完整动画模式可完成主流程。
- [ ] 减少动画模式（`prefers-reduced-motion`）可完成主流程，禁用视差、震波、长镜头和印章缩放。
- [ ] 性能降级模式内容和操作保留，仅移除环境特效。
- [ ] 所有触控目标至少 44px；键盘用户不依赖拖拽。
- [ ] 声音默认关闭，开启后也不能自动播放持续背景音。

## 失败恢复检查

- [ ] 后端停止时自由提问保留当前舞台和问题，可重试。
- [ ] 单个先贤失败时其他席位继续，不导致整场中断。
- [ ] 精选案例的稳定数据明确标注，不冒充实时输出。
