# 投资人追问短答

## 目标用户

悟典首先服务三类人群：

- 面临现实困惑、希望获得文化视角启发的年轻用户，例如职场认可、考试焦虑、人际冲突、选择犹豫。
- 教育和通识内容场景中的老师、社团、课程运营者，用它把经典文本变成可互动的讨论入口。
- 文化内容 IP、出版和知识服务机构，用它验证“经典内容问答化、场景化、可追溯化”的新产品形态。

## 商业模型

短期以 B2B2C 试点为主：

- 教育机构或高校试点：按课程、活动或账号包收费。
- 内容 IP 合作：把特定经典、注疏或主题课程做成可问答的专题入口。
- 个人增强版：面向重度用户提供更多主题、历史记录、学习路径和圆桌讨论能力。

悟典不把自己包装成“万能心理咨询”或“人生决策代理”，而是提供有出处的思想启发。

## 为什么现在

大模型降低了自然语言交互门槛，但普通问答很容易空泛安慰、无法追溯。与此同时，传统经典内容仍停留在课程、书籍和摘录形态，普通人很难把它和当下问题连接起来。

悟典的机会在于：用 RAG 和产品化演示把经典文本变成可问、可查、可复核的入口，让中国思想从“被学习的知识”变成“能参与当下问题的工具”。

## 技术壁垒

悟典的壁垒不只在模型调用，而在可信链路和产品组织：

- 本地经典原文、代表章节和注疏材料的整理。
- 先检索、再生成、可追溯、检索不到不硬编的回答流程。
- 引用块、出处、白话解释和边界提示共同组成的回答结构。
- `/demo -> /sage-chat -> /about -> /roundtable` 的清晰产品路径，让可信问答和多思想圆桌形成可演示闭环。

## 安全边界

悟典定位为思想启发，不替代心理、医疗、法律或职业决策。

产品回答应避免诊断、处方、法律判断、投资建议和替用户做重大决定。遇到高风险内容时，应提示用户寻求专业人士、可信亲友或现实支持系统。检索不到可靠材料时，不硬编经典出处。

## 合作与融资需求

当前最需要四类支持：

- 教育试点资源：高校通识课、社团活动、心理健康前置陪伴和传统文化课程。
- 可信语料合作：经典原文、代表章节、注疏版本和授权内容。
- 内容 IP 合作：围绕人物、学派、主题做可问答专题。
- 早期资金：支持语料整理、评测体系、产品打磨和试点运营。

下一步希望用 2-3 个试点验证留存、复问率、引用点击率和用户对“可追溯回答”的信任提升。
