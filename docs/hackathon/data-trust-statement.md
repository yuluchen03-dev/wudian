# 数据可信说明

悟典的可信口径是：**先检索、再生成、可追溯、检索不到不硬编**。

## 数据来源

当前黑客松演示围绕本地整理材料展开：

- 本地经典原文：用于回答的基础文本依据。
- 代表章节：优先覆盖高频现代问题能关联到的核心段落。
- 注疏材料：帮助解释经典语义，避免只拿短句做断章取义式生成。
- 安全问答缓存：用于演示稳定层和高频问题兜底，保证现场能看到完整回答结构。

这些材料服务于黑客松演示和试点验证，不等同于完整权威古籍数据库。

## 回答结构

悟典回答应尽量包含四层信息：

- 引用块：展示模型依据的经典原文或代表性文本片段。
- 出处：标明书名、章节或可定位来源。
- 白话解释：把原文转译为现代语境下可理解的思想启发。
- 边界提示：说明回答只是思想启发，不替代心理、医疗、法律或职业决策。

## 生成约束

当用户提出问题时，悟典优先检索本地经典原文、代表章节、注疏材料和安全问答缓存，再组织回答。没有检索到可靠依据时，不应硬编出处、伪造章节或把无依据内容包装成经典观点。

统一对外表述：

> 悟典先检索、再生成、可追溯、检索不到不硬编。能引用就给出处，不能可靠引用就提示边界。

## 安全边界

悟典是思想启发产品，不是心理咨询、医疗诊断、法律意见、职业规划或投资建议工具。

遇到自伤风险、严重心理困扰、医疗症状、法律纠纷、劳动争议和重大职业决策等问题时，回答需要提醒用户寻求专业帮助或现实支持。悟典可以帮助用户从中国思想中获得观察角度，但不替用户做决定。
